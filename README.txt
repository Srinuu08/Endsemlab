E-COMMERCE WEBSITE (React + Vite + React Router DOM)

HOW TO RUN:
1. Extract this ZIP file.
2. Open the extracted Ecommerce folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open the Local URL shown in the terminal (usually http://localhost:5173/).

PAGES:
- Home
- Products
- About
- Contact

LAYOUT:
- Header
- Navigation menu
- Sidebar
- Page body
- Footer

React Router DOM is already listed in package.json, so npm install installs it.
